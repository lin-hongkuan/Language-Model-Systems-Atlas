这份练习册把课程中的关键步骤变成可以亲手核对的小题。每题先独立作答，再展开答案。题目使用刻意缩小的数字，目的是看清计算过程；真实模型的词表、维度和数据集会大得多。

## L01：表示为什么重要

词表只有 `猫、狗、汽车` 三个词。把三个词编码成 one-hot 向量，并计算 `猫` 与 `狗` 的点积。

<details>
<summary>答案与解释</summary>

一种编码是：`猫=[1,0,0]`、`狗=[0,1,0]`、`汽车=[0,0,1]`。`猫·狗=0`。所有不同词的 one-hot 向量都正交，因此这种表示不能表达“猫”和“狗”在语义上可能比“猫”和“汽车”更接近。词向量要从上下文中学习这种连续的相似关系。

</details>

## L02：Skip-gram 的 Softmax 与负采样

中心词向量是 `v=[1,0]`，两个候选上下文向量分别是 `u₁=[1,0]` 和 `u₂=[0,1]`。计算两个分数及 Softmax 概率；再计算一个正样本 `u₁` 和一个负样本 `u₂` 的负采样损失：

$$
s_i=u_i^\top v,\qquad \mathcal L=-\log\sigma(u_1^\top v)-\log\sigma(-u_2^\top v).
$$

取 `σ(x)=1/(1+e^{-x})`，可用 `ln 2≈0.693`、`ln(1+e^{-1})≈0.313`。

<details>
<summary>答案与解释</summary>

分数为 `[1,0]`，因此 `P(u₁)=e/(e+1)≈0.731`，`P(u₂)=1/(e+1)≈0.269`。正样本的 sigmoid 概率是 `σ(1)≈0.731`；负样本分数为 0，其被判为负样本的概率是 `σ(0)=0.5`。损失约为 `−ln(0.731)−ln(0.5)≈0.313+0.693=1.006`。Softmax 在候选词之间归一化；负采样只对真实上下文和少量抽样负例计算二分类损失。

</details>

## L03：Softmax 分类器的梯度

一个二分类器对样本输出 logits `z=[ln 3,0]`，真实类别是第 0 类。先算 Softmax 概率，再求交叉熵对 logits 的梯度。

<details>
<summary>答案与解释</summary>

指数分数是 `[3,1]`，所以概率为 `[0.75,0.25]`。对单个样本，交叉熵的梯度是 `p−y`，其中 one-hot 标签 `y=[1,0]`。因此梯度为 `[-0.25,0.25]`。梯度下降更新为 `z ← z−η∇zL`，所以真实类 logit 上升、另一类下降，模型会把更多概率分配给真实类。

</details>

## L04：语言模型概率与困惑度

模型给一个两词目标序列的真实下一个词概率依次为 `1/2` 和 `1/4`。求整个序列的概率、平均负对数似然和困惑度。

<details>
<summary>答案与解释</summary>

序列概率是条件概率之积：`(1/2)(1/4)=1/8`。平均负对数似然是 `−(ln(1/2)+ln(1/4))/2=(3/2)ln 2≈1.040`。困惑度是其指数：`exp(1.040)=√8≈2.83`。困惑度越低表示模型给真实 token 的概率越高，但只有在 tokenization 和评估语料一致时才适合比较。

</details>

## L05：手算缩放点积注意力

令查询 `q=[1,0]`，两个 key 是 `k₁=[1,0]`、`k₂=[0,1]`，对应 value 为 `v₁=10`、`v₂=0`。按 `softmax(qKᵀ/√2)V` 计算注意力权重和输出；然后加入因果遮罩，使第一个位置不能看第二个位置。

<details>
<summary>答案与解释</summary>

未遮罩分数为 `[1/√2,0]≈[0.707,0]`，Softmax 约为 `[0.67,0.33]`，输出约为 `0.67×10+0.33×0=6.7`。第一个位置不能看未来 key 时，第二个分数应在 Softmax 前设为 `−∞`，权重变成 `[1,0]`，输出为 `10`。遮罩必须在 Softmax 前作用于 logits。

</details>

## L06：识别实验混杂因素

你比较两种检索切片长度，发现长切片系统的问答准确率更高。但长切片还用了更大的语言模型和不同提示词。你能否得出“长切片提升准确率”？下一次实验如何修正？

<details>
<summary>答案与解释</summary>

不能。模型大小、提示词和切片长度同时变化，结果无法归因到其中某一个因素。先固定语料、模型、检索器、提示词、top-k、评测集和解码配置，只改变切片长度；再报告回答质量、检索证据指标和资源成本，并查看错误案例。如果也想比较模型大小，应使用二维实验表，把模型大小和切片长度分别列为控制变量。

</details>

## L07：估算预训练计算量

用粗略关系 `训练 FLOPs≈6ND` 估算一个参数量 `N=10^8`、训练 token 数 `D=10^9` 的密集 Transformer 训练计算量。此估算忽略了不少具体架构和数据管线细节。

<details>
<summary>答案与解释</summary>

`6×10^8×10^9=6×10^17 FLOPs`。这个数帮助比较规模，不是精确的 GPU 运行时间：实际时间还取决于注意力实现、序列长度、利用率、通信、重计算、硬件峰值和输入管线。

</details>

## L08：DPO 的偏好概率

设 DPO 的隐式偏好概率是 `p=σ(β[(logπ(y⁺|x)−logπ(y⁻|x))−(logπ_ref(y⁺|x)−logπ_ref(y⁻|x))])`。当前策略的偏好 log-ratio 为 `0.4`，参考策略为 `0.1`，`β=0.1`。估算 `p` 及单样本损失 `−ln p`。

<details>
<summary>答案与解释</summary>

括号内差值是 `0.4−0.1=0.3`，乘以 `β` 得到 `0.03`。`σ(0.03)≈0.5075`，损失约 `−ln(0.5075)≈0.678`。当策略相对参考策略提高了偏好回答的概率时，括号倾向为正，偏好概率高于 0.5，损失下降。

</details>

## L09：LoRA 参数量

一个线性层权重矩阵形状为 `128×64`。使用 rank `r=4` 的 LoRA 替代直接更新完整矩阵，比较完整参数量和 LoRA 可训练参数量（忽略 bias）。

<details>
<summary>答案与解释</summary>

完整矩阵有 `128×64=8192` 个参数。LoRA 使用 `A∈R^{4×64}` 和 `B∈R^{128×4}`，共有 `4×64+128×4=768` 个参数，约为完整矩阵的 `9.375%`。低秩适配节省可训练参数和优化器状态，但最终效果仍需实测。

</details>

## L10：检索召回率

一个问题有 4 段人工标注的相关证据。系统前 5 名检索结果中找到了其中 3 段。求 `Recall@5`，并解释它不等于答案正确率。

<details>
<summary>答案与解释</summary>

`Recall@5=3/4=0.75`。它衡量相关证据被检索到的比例。生成器可能误读已经检索到的证据，或引用错误；即使答案正确，检索结果也可能没有完整证据。因此还需分开评估检索、生成事实性和引用正确性。

</details>

## L11：分类指标

某分类器的混淆矩阵统计为 `TP=40, FP=10, FN=20, TN=30`。计算 accuracy、precision、recall 和 F1。

<details>
<summary>答案与解释</summary>

总数是 100。`accuracy=(TP+TN)/100=0.70`，`precision=TP/(TP+FP)=0.80`，`recall=TP/(TP+FN)=2/3≈0.667`，`F1=2PR/(P+R)≈0.727`。类别比例不均衡时，accuracy 可能掩盖少数类性能；还应报告每类指标、宏平均或适合任务的其他指标。

</details>

## L12：温度与 nucleus sampling

三个 token 的 logits 是 `[2,1,0]`。把温度设为 `T=2` 后 logits 变为 `[1,0.5,0]`。用近似概率 `[0.506,0.307,0.186]` 执行 `top-p=0.7` nucleus sampling：保留哪些 token，截断后归一化概率约为多少？

<details>
<summary>答案与解释</summary>

按概率从高到低累加：最高项只有 `0.506<0.7`，前两项累计 `0.813≥0.7`，所以保留前两个 token，丢弃第三个。归一化后约为 `[0.506/0.813,0.307/0.813]≈[0.622,0.378]`。温度改变分布尖锐程度；top-p 再根据累计概率动态截断候选集合。

</details>

## L13：推测解码接受率

草稿模型给某 token 概率 `q(x)=0.8`，目标模型给 `p(x)=0.6`。按接受概率 `min(1,p(x)/q(x))`，这个 token 被接受的概率是多少？

<details>
<summary>答案与解释</summary>

`min(1,0.6/0.8)=0.75`。推测解码不是无条件相信草稿模型：目标模型会校验候选，并在不匹配时修正采样，目标是加速生成同时保持目标分布。

</details>

## L14：BPE 的第一次合并

字符级 token 序列及频次如下：`a b c` 出现 2 次，`a b d` 出现 2 次，`a c d` 出现 1 次。忽略词边界符号，哪一对相邻 token 的频次最高？第一次合并是什么？

<details>
<summary>答案与解释</summary>

`a b` 出现 4 次，`b c`、`b d` 各 2 次，`a c`、`c d` 各 1 次。因此第一次合并 `a b→ab`。BPE 反复合并语料中最常见的相邻符号对，直到达到词表预算；最终 token 边界是由语料频次学习到的。

</details>

## 综合自测：从一个文本到可核验结果

选一段小型中文文本，按顺序写出：

1. tokenization 后的 token 和 token ID；
2. 一个 context window 下输入序列与右移一位的目标序列；
3. logits、交叉熵和下一个 token 的预测；
4. 训练/验证划分以及一个不会泄漏答案的评估指标；
5. 贪心解码与采样解码可能不同的原因。

核对标准：每一步的 shape 可对上；目标只比输入向右错开一位；loss 只对有效目标 token 汇总；评估集不参与调参；解码策略不会改变训练目标，只改变推理时如何从概率分布选 token。
